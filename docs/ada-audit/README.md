# Nous Nails ADA audit (HTML)

Open **`index.html`** in a browser (double-click, or from this folder run `python3 -m http.server 4173` and visit http://localhost:4173/).

## Review

- Filter by severity, status, or search
- Set each finding to Open / In progress / Done
- Add notes on a card
- Check off the fix list

Status and notes save in this browser (`localStorage`). Use **Export progress** / **Import progress** to move that work to another machine.

## Update the findings

Edit the `REPORT` object near the bottom of `index.html` (titles, WCAG, files, fixes, screenshots). Screenshots live in `images/`.
